# Smart Contract Lottery

A decentralized lottery built with Solidity and Foundry, using Chainlink VRF v2.5 for verifiable randomness and Chainlink Automation for upkeep.

## Technologies
- Solidity
- Foundry
- Chainlink VRF v2.5
- Chainlink Automation
- OpenZeppelin Contracts

## Project Structure
- `src/` — Smart contract
- `script/` — Deployment and interaction scripts
- `test/unit/` — Unit tests
- `test/staging/` — Staging tests
